# Water Potential Calculator v1.1.0 — Release Notes

## Release focus

Version 1.1.0 is the field-user productization release. It preserves the protected calculation methodology while redesigning the public product for field engineers, practitioners and programme/M&E users.

## Main changes

- Public identity changed to **Water Potential Calculator** with the subtitle **Water Potential · Participation · Reporting**.
- Normal frontend wording was rewritten in practitioner language and HUF/development identifiers were removed from routine screens.
- Added a launch page with the Upload → Check → Calculate → Explore → Report journey and web-only developer profile links.
- Redesigned Results, Structure Intelligence and the daily water-balance trace using a cleaner analytical visual grammar.
- Redesigned Management and Technical/M&E PDF outputs with cover pages, readable precision and clearer information hierarchy.
- Removed personal branding and machine/audit identifiers from normal PDF/CSV/XLSX/JSON/ZIP reporting outputs.
- Kept controlled internal identifiers and hashes in specialist audit surfaces where they are useful.
- Added live GitHub Pages deployment validation, live field-user browser acceptance and fixed-budget synthetic capacity acceptance.
